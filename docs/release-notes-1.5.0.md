## Instamony v1.5.0

HarmonyOS NEXT 原生客户端。这一版是三件大事：**登录整条换掉**（网页登录 → App 协议 CAA + 两套 2FA）、**Reels 从头重做**（下拉刷新、看过不再给、一人一条、翻页真能翻）、以及**把 WebView 收口到只剩"账号安全验证"**。同时清掉约 5k 行发布前不该带的死代码与探针采集。

> 安装说明：`.app` 与 `.hap` 都是**调试证书签名**（可侧载），直接 `hdc install` 或应用市场外的安装器即可。换签名（发布证书）后必须卸载重装，登录状态会丢。
>
> 资产说明：`.app` 未压缩；GitHub 只接受 zip 类附件，所以另附一份 `.app.zip`（**就是 .app 加了个 .zip 后缀，没有重新压缩**）。

### 新增功能

**登录：整页换成 App 协议登录（CAA）**
- 登录页只剩一处：账号 + 密码 + 登录 / 注册。网页登录（隐藏网页里代填）整条移除。
- 走 IG 自己 App 那条路：USDID 设备签名 → attestation → Bloks 编排，拿到的是**设备级会话**（后台推送、私信才工作得正常）。
- 传输层换成**自建 TLS 1.3 客户端**（对齐 IG 接受的 ClientHello）。这是"密码登录被回 429、电脑上同一份请求却 200"的根因。
- **两套 2FA 都认**：新版 `two_step_verification_context` 链（验证器/短信/备用码）与旧 `ap.*` 链；每跳两个域名自动回退。
- 2FA 用**系统沉浸光感半模态面板**收码，不再占页面。
- 登录页标题栏新增「设置」入口（图标与「我的」页一致）；设置页未登录时不显示「退出登录」，改显示「登录与设备 → 清除设备认证（2FA 测试）」（换新 USDID + 8 个 UUID，让 IG 把下一次登录当成新设备，2FA 才测得出来）。

**网络：DoH（DNS over HTTPS）**
- 新增 RFC 8484 解析器（IP 直连端点 + 域名回退、TTL 缓存、30 秒负缓存、3 秒超时），接到自建 TLS 1.3 登录链的域名解析上；证书与 SNI 仍按域名走。
- 设置页新增「网络」组：开关 + 「测一下 DoH 解析（i.instagram.com）」+ 现场一行（端点数量/缓存条数/最近一次结果）。任一步失败自动退回系统解析。

**Reels：下拉刷新、看过不再给、一人一条**
- **下拉刷新**（与"触底翻页"明确分开）：在第一条上往下拖过阈值就刷新，顶部出现沉浸光感胶囊提示；刷新是**换一批**，不是重读首屏。
- **看过的视频落盘记账**（按账号/按流分区，最多 500 条）：再次打开 app 不再给上一轮同一批，下拉刷新也严格不给看过的。
- **一人一条**：整份列表里同一个作者只出现一次，且不会连着两条同一个人；补货时先打散再上屏。
- 首屏提速：等启动预热而不是重发；只预载可见那一段；冷启动只给两发。
- 预取提前备好后两条；触底那一刻不再死等慢预取（在飞的是"流那页"就直接自己要一发作者页）。
- 作者页一次只要 4 条（"一人一条"下 12 条里只有 1 条用得上，剩下 11 条是白流量）；池子里已经上屏过的作者直接摘掉。

**信息流**
- 下拉刷新一定发新请求、成功即收转圈、刷新后回顶部并整体替换列表。
- 关注流按 id 现问关注状态（`friendships/show/{id}/`），未关注作者的帖子不再出现。

**账号**
- 退出登录**真正清干净**：账号分区、按人缓存、诊断文件、CAA 痕迹、FBNS 凭据、reels 台账、`@anon` 匿名分区…最后只留设备身份（uuid/phoneId/mid/USDID）与匿名偏好。

**底栏**
- 点当前项：列表不在顶部 → 回顶部；已在顶部 → 刷新。

### UI

- **2FA 面板**：标题接入半模态自带的 HDS 标题（和设置页那两个代理面板同一套）；面板禁用触摸发光；登录按钮在面板打开期间保持转圈；密码不再被清空。
- **实色按钮**：「登录 / 验证并登录」改成**沉浸光感 + 华为品牌蓝（#0A59F7）**——颜色交给材质（`materialColor`），背景透明，触摸那道光才浮在蓝底之上可见（以前不透明底色把材质挡死了）。
- **Reels**：刷新提示与倍速提示统一成一颗沉浸光感胶囊（`MaterialPill`），缩小留白、下移到 HDS 标题栏下方；卡片内那颗倍速胶囊去掉。
- **登录页**：去掉网页登录入口；标题栏右上角一颗「设置」（`sys.symbol.more`，与「我的」页一致）。
- **搜索页**：标题栏改成滚动联动、探索流穿到栏底下；顶部黑块补了一次页面底色兜底。
- **快拍 / highlight**：卡片内部右下角加静音键，绑定全局静音。
- **会话页标题栏**：恢复 HDS 标题栏 —— 返回键 + 头像 + 标题（群聊用群名）+ menus。

### 手势

- **Reels 下拉刷新**：下拉位移超过 96vp 触发；阻尼 0.5、最多跟到 168vp；往上滑超过 24vp 取消；空列表状态下也能拉。
- **底栏点同一项**：列表不在顶部 → 回顶部；已在顶部 → 再点一次触发刷新（点完还有一小段"吞点击"窗口，避免这一下穿到内容里）。
- **手势返回（系统返回键 / 返回手势）**：
  - 在 Reels / 私信 / 搜索 / 我的 页 → **优先回主页**（这些页是 tab 内状态、不是压栈页面）；
  - 搜索页有结果时 → 先回"推荐流"，不退出；
  - 在主页 → 第一次弹提示「再次返回到桌面」，**2 秒内**再返一次才退出到桌面。

### 修复

- **Reels 翻页永远"固定那几条"**：`clips/*` 的游标必须放在 **form body**，放查询串时服务端直接无视、把同一页重排后还回来。改到 body 后第二页 16 条 / 15 个作者 / 与第一页 0 重合。
- **Reels 刷新后封面是新的、播放的还是旧的**：ForEach 的 key 带上"代"（`feedGen#shortcode`），并在视图模型里加 epoch 让作废的异步结果不再写回。
- **Reels "看完一页要等很久"**：预取的在飞标记在 epoch 变动时直接 `return`，永远停在 true，预取从此停摆；触底又无条件等 12 秒。两处都修。
- **Reels "前几条要等很久"**：`loadFirst` 里那句"后台补几条"是在 `busy` 还开着时调的（`requestMore` 第一句就 return）—— 首屏之后有 10 秒一个请求都没有。改成首屏收尾时真正发起。
- **Reels 刷新后连续 12 条同一个人**：补货攒够两家作者再交替上屏，且"一人一条"硬规则。
- **密码登录被 IG 回 429**：根因是系统 TLS 栈的 ClientHello 指纹；自建 TLS 1.3 后真机可登录。
- **登录设备身份 `mid` 为空**（等于一台 machine_id 空的"假客户端"）；**设备级会话没有 sessionid** 时解析与 Cookie 罐都不认；导入会话后判"不是这个账号"、"登录态翻转把它抹掉"。
- **换会话后后台推送不响**：FBNS 不再只认设备级会话，换会话时连同 FBNS 一起重启。
- **"退出登录没清干净"**：见上「账号」。
- **信息流**："第一条固定 / 之后刷不动"、"刷新转圈不收"、"刷新后不回顶部"。
- **通知**：点击直达会话（wantAgent + `instarmony://open?route=direct&id=…`）、"第一次点没反应"（回前台补一次跳转）、标题显示成数字 id（补发信人用户名解析，带缓存）、标题"有时候变成私信"。
- **私信**：群聊名字/头像串了、"被占了"就抹空、贴图被画成分享卡片、图片宽度与气泡样式。
- **安全**：内置网页的域名白名单（`instagram.com / cdninstagram.com / fbcdn.net / facebook.com`），站外链接一律系统浏览器。

### 工程 / 清理

- **WebView 收口**：隐藏 WebView 现在**只用于「账号需要安全验证」**那一页（它必须带着本机会话才能完成）。
  - 点帖子 → **原生帖子页**（信息流整份列表带进去；主页格子/搜索结果/深链这种只有短码的走新的 `openLoosePost`，缺的字段由原生按 media id 补）。
  - 评论只走原生 HTTP（去掉"网页导航到帖子页 + 注入脚本读 DOM"的兜底）；收藏 / 评论点赞 / 关注的"网页驱动兜底"全部删除。
  - 注册新账号、站外链接、深链 → **系统浏览器**。
  - 删除无头网页登录（`core/WebLogin.ets`，1325 行）及其入口；WebView 宿主改为**按需挂载**，启动时不再预先挂一个网页实例。
- 删除发布前不该带的死代码与采集：`CaaLoginCard`、`MainThreadWatchdog`、`MobileLogin`（旧 REST 登录链）、`ProbePanel`、探针自动落盘（60 秒一次写沙箱）、登录链路的传输探针（rcp / TLS 变体 / 连接探针等）、2FA「在另一台设备上同意」整条调查链。共约 **5000 行**。
- 版本号：**1.5.0**（versionCode **1005000**）；产物在 `release/v1.5.0/`。

### 已知问题 / 待办

- **2FA「在另一台设备上同意」用不了**：IG 那一发 (`has_been_allowed.async`) 我们打得通、也回 `waiting`，但在 Instagram 官方客户端点"同意"一律回"**这个登录请求已失效**"（五版对照实验，含清空通知重测）。判断是 IG 只允许官方 App 之间互批，第三方客户端拿到的通知天然批不了。已撤掉界面承诺，实现留档在 `CaaLogin` / `CaaSession` 注释里。
- **Push Kit 在侧载包上不可用**（`1000900010 Illegal application identity`）：必须走 AppGallery 邀测/上架。离线通知目前仍靠**自建中转 + IM 机器人**（`tools/relay`）。
- **Reels 闪退**：只加了取证与两处加固（播放器摘表面、会话异常结束标记、播放器计数），根因仍未被完全证明。
- **DoH 只作用于登录链**：信息流 / 媒体仍走系统解析。
- `WebScripts` 里还留着 19 个已无调用方的旧脚本常量（点赞/收藏/评论/关注/搜索/私信/探针）；牵连内部共享变量，这版先不动。
- 长时任务（常驻后台）未做：私信检查不属于任何 `backgroundModes` 类型。
