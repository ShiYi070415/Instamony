# 多设备验收结果

> 设备：平板 `192.168.3.105:12345`（2800×1840，横屏，浅色模式）
> 构建：`hvigorw assembleHap --mode module -p product=default -p buildMode=debug --no-daemon`
> 包：`entry-default-signed.hap`

## 已通过

| 场景 | 结果 | 证据 |
|---|---|---|
| 冷启动 / 首页 | 通过 | 侧边栏第一列、标题栏、信息流正常 |
| 侧边栏安全区 | 通过 | 顶部展开按钮避开状态栏；底部通知/设置避开手势条 |
| 双栏布局 | 通过 | 分割线位于左栏右边界，右栏铺满到右侧 |
| 私信会话 | 通过 | 左列表 + 右会话，输入条避让底部系统条 |
| 设置页 | 通过 | 设置页只在内容区滑入，侧边栏保持可见 |
| 浅色 Reels | 通过 | 侧边栏普通底色/深色图标；标题与资讯栏左对齐 |
| Reels 滑动 | 通过 | LazyForEach + Reusable 连续上滑，作者/正文/计数正确切换 |
| 通知失败态 | 通过 | 空态显示“重试”，复用下拉刷新 |
| 快拍回复条 | 通过（构建） | 底部回复条传入 `bottomSafeVp`，避开手势条 |

## 未覆盖

| 场景 | 原因 |
|---|---|
| 手机 Compact 断点 | 当前只有平板设备；`hdc shell wm` 不可用，无法改分辨率模拟 |
| 折叠屏 Medium 断点 | 无折叠屏设备，也无法用 wm 改窗口 |
| 系统深色模式 | 本轮只测浅色；深色需另跑一轮 |
| 字体 1.3x / 无障碍对比度 | 需要系统设置切换后逐页检查 |
| 软键盘弹起 | 当前 adb 输入点击未拉起软键盘，需人工在设备上验证 |

## 结论

平板主路径已验收；手机/折叠/深色/字体/键盘仍需设备或人工补测。单栈 Navigation Split 不实施，见方案文档“架构决策”。
