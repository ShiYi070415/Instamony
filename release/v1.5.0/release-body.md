## Instamony v1.5.0

三件事：**登录整条换掉**（网页登录 → App 协议 CAA + 两套 2FA）、**Reels 重做**（下拉刷新 / 看过不再给 / 一人一条 / 翻页真能翻）、**WebView 收口到只剩「账号安全验证」**。另外清掉约 5000 行发布前不该带的死代码与探针采集。

> `.app` 与 `.hap` 都是调试证书签名（可侧载）。`.app.zip` 就是 `.app` 加了个 `.zip` 后缀（**未压缩**），因为 GitHub 不放心收 `.app`。

### 新增功能

- **登录换 App 协议（CAA）**：账密 → USDID 设备签名 → attestation → Bloks 编排，拿到**设备级会话**；传输层换**自建 TLS 1.3**（这才是密码登录被回 429 的根因）。两套 2FA 都认（新版 context 链 / 旧 ap 链，双域名自动回退），验证码走**系统沉浸光感半模态面板**。
- **未登录也能进设置**：登录页标题栏加「设置」；设置页未登录时不显示「退出登录」，改显示「登录与设备 → 清除设备认证（2FA 测试）」。
- **DoH（DNS over HTTPS）**：接在登录链的域名解析上，设置页可开关 + 一键探测。
- **Reels**：下拉刷新（与翻页分开）、看过的视频落盘记账（刷新不再给看过的）、一人一条（同一作者不连着出现、整份列表只出现一次）、刷新真的换内容。
- **信息流**：下拉刷新一定发新请求、成功即收转圈、刷新后回顶部；关注流按 id 现问关注状态，未关注作者的帖子不再出现。
- **退出登录真的清干净**（分区/缓存/诊断/CAA 痕迹/FBNS 凭据/reels 台账），只留设备身份与匿名偏好。
- **底栏点当前项**：不在顶部 → 回顶部；已在顶部 → 刷新。

### UI

- 2FA 面板：标题接入半模态的 HDS 标题、**禁用触摸发光**、面板期间登录按钮保持转圈、密码不清除。
- 实色按钮（登录 / 验证并登录）：沉浸光感 + **华为品牌蓝 #0A59F7**（颜色交给材质，触摸那道光才看得见）。
- Reels：刷新与倍速统一成一颗沉浸光感胶囊，缩小留白并下移到标题栏下方。
- 登录页设置图标与「我的」页一致；搜索页标题栏滚动联动、探索流穿到栏下；快拍卡片加静音键；会话页标题栏 = 返回 + 头像 + 标题 + menus。

### 手势

- Reels 在第一条上下拉 >96vp 触发刷新（阻尼 0.5、最多 168vp、上滑 24vp 取消）。
- **底栏跟随滚动**：内容上滑 → 底栏**下沉收缩**（往下挪 10vp、收窄 60vp、缩矮 15vp，走弹簧曲线），往回滑即恢复；Reels 页跟着下沉的是动作区/资讯区，底栏不挡视频。
- **底栏显隐可切**：设置 → 底栏 → 「底栏原生动效」关掉后改用 HDS 的系统显隐（滚动时整条栏收走/放出）。
- **点当前页签**：列表不在顶部 → 回顶部；已在顶部 → 刷新（点完有一段"吞点击"窗口，避免这一下穿到内容里误触）。


### 修复 bug

- Reels "固定那几条"：`clips/*` 游标必须放在 **form body**（放查询串会被服务端无视）。
- Reels 刷新后"封面是新的、播放是旧的"：ForEach key 带上代 + 视图模型 epoch 作废旧结果。
- Reels "看完一页/前几条要等很久"：预取在飞标记泄漏 + 首屏那句补货被 `busy` 挡掉 + 触底死等慢预取。
- Reels "连续 12 条同一个人"：攒够两家作者再打散上屏。
- 登录：429（TLS 指纹）、`mid` 为空、设备级会话无 `sessionid`、导入会话被判"不是这个账号"、换会话后后台推送不响。
- 信息流："第一条固定 / 之后刷不动"、刷新转圈不收、刷新不回顶部。
- 通知：点击直达会话、"第一次点没反应"、标题显示数字 id。
- 私信：群聊名字/头像串了、贴图被画成分享卡片、图片宽度与气泡样式。
- 安全：内置网页域名白名单，站外链接一律系统浏览器。

### 待办 / 已知问题

- **2FA「在另一台设备上同意」不可用**：IG 官方客户端点同意一律回"登录请求已失效"（五版对照，含清空通知重测），判断是 IG 只允许官方 App 互批；界面承诺已撤掉。
- **Push Kit 侧载不可用**（需 AppGallery 邀测/上架）；离线通知仍靠自建中转（`tools/relay`）。
- **Reels 闪退**根因未完全证明，只加了取证与加固。
- DoH 只作用于登录链；`WebScripts` 里 19 个旧脚本常量暂留；长时任务未做。
