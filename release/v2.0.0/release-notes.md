# Instamony 2.0.0 —— 越南语/意大利语、平板 UI 与一轮稳定性修复

> 版本：`versionName 2.0.0`（`versionCode 2000000`）
> 包名：侧载 HAP `com.yijin.instamony`；AGC 邀测 App Pack `com.oneleaf.instamony`　最低 API：6.0.0(20)　目标 API：26
> 签名：DevEco Studio + debug 证书（可侧载；`.app` / `.hap` 均为已签名产物）

2.0.0 是 1.6.0 之后的一次集中更新：**新增越南语和意大利语**、**平板专属 UI**、
**多图媒体保存**、**快拍切下一位卡顿优化**、**故事下载**，以及 Reels 稳定性与
侧载共存的一轮修复。

> `.app.delete` 就是 `.app` 加后缀（GitHub 不收 `.app` 原始文件名）；下载后去掉
> `.delete` 即为 App Pack。`.hap` 可直接 `hdc install`。

## 1. 新增语言

- 在原有 **简体中文、繁体中文、English、日本語、한국어、Español、Deutsch** 七套资源上，
  新增 **Tiếng Việt（越南语）** 与 **Italiano（意大利语）**，共 **9 种语言**。
- 设置页「语言」列表已加入两项，支持搜索与即时切换。
- 翻译链路会按当前 App 语言选择目标语言，不再固定跟随系统语言。
- 新增文案继续走资源键，避免硬编码。

## 2. 多图媒体保存

- 多图帖的下载按钮不再只保存当前/第一张。
- 点一次下载：先取该帖全部原图地址，逐张下载到沙盒，再通过**一次**系统授权窗
  写入相册，最后统一清理临时文件。
- 视频、单图帖仍走原来的单文件路径。
- 保存完成会提示实际保存张数；部分失败时保留已成功的张数。

## 3. 快拍切换下一位用户

- 快拍卡片继续使用前后两张预渲染结构，切换下一位用户时优先播放翻页动画，
  媒体未就绪时先显示卡片与加载态。
- 预取窗口按网络自适应：Wi-Fi 预取 8 位用户、每位前 3 条媒体；
  蜂窝/未知网络降为 3 位用户、每位 1 条，减少弱网下切卡等待。
- 最近看过的用户快拍加入内存缓存，来回切换不重复拉取。
- 媒体就绪后再换正面，减少黑闪和空卡。

## 4. 平板 UI

- 侧边栏改为独立第一列，固定窗口高度，页面内容独立参与键盘 `RESIZE`。
- 侧边栏顶部/底部按钮分别避让状态栏/手势条；设置页滑入时侧边栏保持最顶层。
- 左右栏宽度统一按同一份内容区计算，分割线与右栏不再错位，右栏会话铺满右侧。
- Reels 标题、资讯栏、正文统一左边线；正文/动作区避让底部系统条。
- 登录页、设置页、通知页、帖子页、用户主页、会话页、Reels 详情页统一使用
  页面级 destination 宿主。
- 三折叠展开态登录表单限宽 560vp 并居中，不再横向拉满整屏。

## 5. 其他设备同意登录

- 新增 **2FA 跨设备同意**：账号在另一台设备触发登录确认时，本机会进入“等待同意”状态，
  持续轮询并自动完成登录，不用再手动输验证码。
- 若 IG 仍要求验证码，会继续弹原有的验证码面板，两种方式并行。
- 等待同意期间登录按钮保持转圈；切走页面会停掉轮询定时器，避免后台空转。

## 6. 故事下载

- 快拍/Highlight 卡片增加下载按钮，按**当前媒体 index** 下载，不再固定第一张。
- 图片保存原图，视频保存原视频；右下角静音键与下载键在同一组。
- 实现在 `core/MediaDownloader` 与 `StoryViewer` 的下载解析里，支持前后两张卡片。

## 7. 侧载/邀测共存

- 侧载 HAP 使用 **`com.yijin.instamony`**，AGC 邀测 App Pack 使用
  **`com.oneleaf.instamony`**；两个包可同时安装、互不覆盖。
- AGC 包与旧版 1.6 的 `com.oneleaf.instamony` 同包名，会作为升级覆盖正式版；
  侧载 HAP 用独立包名，可与 AGC 包并存。
- 两个包各自持有自己的会话与缓存；首次安装 2.0.0 需要重新登录，旧包数据不会自动迁移。

## 8. Reels 稳定性

本轮继续收敛 Reels 闪退，重点是播放器生命周期：

- 播放器预算与串行创建抽成 `ReelsPlayerPool`：进程内预加载播放器上限 1，
  全局同一时刻只允许一个 `createAVPlayer` 在飞。
- Swiper 从 `ForEach` 改为 `LazyForEach` + `ReelsDataSource`，只保留当前与相邻页。
- `ReelSlide` 加 `@Reusable`，复用时复位暂停/拖动/尺寸状态。
- `VideoSurface` 保留 player/epoch 校验，旧 player 回调不再操作新页面。
- 快照/封面背景、首帧、进度上报继续走原保护逻辑。

> 闪退受设备解码器、网络和视频源影响，本轮是**继续收敛**，不能保证所有机型/所有视频
> 都不再触发；如仍遇到，请在设置 → 诊断导出日志。

## 9. 其它修复

- 换账号时主动取消在飞 HTTP 请求，清空只读请求合并表、通知代次、关注/收藏 busy 与
  关注/收藏/转发/已看覆盖表，减少串号。
- 会话输入框键盘避让改为页面级 `RESIZE` + 输入条贴底；删除旧的自校正代码。
- 评论输入条、快拍回复条、Reels 正文/动作区统一避让底部系统条。
- 页面内容顶部由固定 94vp 改为 `topSafeVp + 66`，适配不同状态栏高度。
- 通知页失败态新增「重试」按钮。

## 10. 已知问题

- **Push Kit 侧载不可用**（需 AppGallery 邀测/上架）；离线通知仍靠自建中转。
- 部分旧接口仍可能被 IG 限流（429），设置页「诊断」可导出日志。
- 多图保存会先逐张下载再弹一次系统授权窗；图片很多时等待时间会变长。
- 深色模式、字体 1.3x、无障碍对比度尚未完成全量设备验收。
